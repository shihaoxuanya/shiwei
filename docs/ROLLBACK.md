# 暂停、撤销与回滚发布目标

1. 暂停：进入当前版本详情，选择暂停，确认版本号与原因。后续 Update Check 立即返回无更新；尚未点击安装的客户端会在下载前再次校验并取消。
2. 撤销：用于严重问题，确认后版本不再分发且不能恢复。重新提交 CI 元数据不会复活版本。
3. 回滚发布目标：从当前目标选择较低、已全量发布、已验证、未撤销的安全版本，停止当前版本并将 target 切回安全版本。已安装新版本的客户端不会降级。后台不删除安装资源或用户资料。
4. 优先前向修复：发布更高 SemVer 的修复版本。普通发布不能利用更低版本绕过回滚审计。

暂停策略不能撤回已经被匿名用户下载到本地的公开 GitHub 安装包。这里控制的是客户端更新推荐，不是 GitHub 文件的访问权限；不承诺远程删除用户已持有的安装包。

涉及数据兼容时先使用隔离资料库运行旧 schema fixture 升级测试。手动降级不属于当前更新协议，绝不能通过修改 schema marker 让旧程序打开未知的新数据库。
