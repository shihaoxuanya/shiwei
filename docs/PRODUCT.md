# 拾微 MVP 产品定义

## 核心价值

拾微帮助普通用户把历史文件、文件夹和随手记录留在本机，在不手工分类的情况下，通过自然语言重新找到过去看过、学过、记过和做过的内容，并查看可靠原始出处。

> 你不用整理，它替你记住。

## MVP 验证

MVP 只验证一条闭环：资料导入或随手记录 → 自动处理 → 精确与语义混合检索 → AI 基于资料回答 → 引用可追溯 → 打开原文件或原笔记。

必须同时满足：

- 文件夹可以一次导入，单文件失败不影响整个任务。
- 没有模型配置时仍可导入、浏览资料和全文搜索。
- 精确术语、错误码、文件名、IP 和 SQL_ID 可以通过 FTS 找回。
- 用户只记得含义时可以通过语义检索找回。
- AI 不把无来源推测描述为用户过去的事实。
- 原始文件永不被 AI 改写，派生索引可删除并重建。

## 用户流程

首次打开 → 配置可替换模型 → 拖入文件夹 → 查看处理进度 → 直接提问 → 查看带引用的回答 → 在来源抽屉核对原文 → 打开文件或在资源管理器中显示。

## 界面范围

- 首页：欢迎、文件/文件夹导入、处理进度和“记一下”入口；不重复放置对话输入框。
- 对话：会话列表、流式回答、引用标签、来源抽屉和错误状态。
- 资料：文件列表、状态、搜索、打开、定位、重建索引和删除。
- 笔记：创建、纯文本编辑、自动保存、列表、搜索和删除；不做文件夹、标签或富文本系统。
- 设置：模型设置、安全凭据、重建入口，以及 v0.3 的关于/签名更新与隐私开关；技术版本信息折叠到开发者信息。

## 明确不做

账号、云知识库、同步、用户内容上传、移动端、协作、笔记文件夹/标签、知识图谱、Markdown 富文本编辑器、插件市场、工作流、Agent、GraphRAG 和复杂企业权限均不属于 MVP。

v0.3 明确授权最小发布控制面：版本/构建/签名更新、基础使用统计与错误报告、仅本地实现的 Feature Flag 接口。2026-09-06 的后台完善任务将新生产安装的基础统计调整为默认开启、不弹确认框，保留明确说明和关闭入口；已有关闭选择不变。自有管理后台只提供汇总指标和版本管理，不拥有个人知识，不改变核心检索闭环；详见 [ANALYTICS_DASHBOARD.md](ANALYTICS_DASHBOARD.md) 和 [PRIVACY_TELEMETRY.md](PRIVACY_TELEMETRY.md)。此前“不做遥测／默认关闭”的边界由明确任务有限替代。

## 最终验收

在新 Windows 电脑安装后，导入 `fixtures/demo-knowledge`，询问“我之前数据库恢复以后 PDB 打不开是怎么解决的？”，系统必须召回 Oracle 记录、生成基于资料的回答、显示引用片段，并能打开对应文件。
