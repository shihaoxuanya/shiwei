# 拾微 MVP 产品定义

## 核心价值

拾微帮助普通用户把历史文件、文件夹、公开网页正文和随手记录留在本机，在不手工分类的情况下，通过自然语言重新找到过去看过、学过、记过和做过的内容，并查看可靠原始出处。

> 你不用整理，它替你记住。

## MVP 验证

MVP 只验证一条闭环：资料导入或随手记录 → 自动处理 → 精确与语义混合检索 → AI 基于资料回答 → 引用可追溯 → 打开原文件或原笔记。

必须同时满足：

- 文件夹可以一次导入，单文件失败不影响整个任务。
- 没有模型配置时仍可导入、浏览资料和全文搜索。
- 精确术语、错误码、文件名、IP 和 SQL_ID 可以通过 FTS 找回。
- 用户只记得含义时可以通过语义检索找回。
- AI 不把无来源推测描述为用户过去的事实。
- 原始文件永不被 AI 改写，派生索引可删除并重建。

## 用户流程

首次打开 → 添加文件/文件夹或记一下 → 查看保存与处理状态 → 按关键词找回；需要 AI 生成时配置可替换模型 → 直接提问 → 查看带引用的回答 → 在来源抽屉核对原文 → 打开文件或原笔记。未配置 API Key 仍可使用已有本地导入、笔记和关键词检索能力。

## 界面范围

- 首页：空库欢迎、文件/文件夹导入和清晰的“记一下”入口；有内容后使用紧凑欢迎、真实处理/失败反馈及最多五条最近资料或笔记，不重复放置对话输入框。正常本地服务状态只作低干扰提示，故障提供可操作提示。
- 对话：会话列表、流式回答、引用标签、来源抽屉和错误状态。
- 资料：复用同一导入入口、文件列表、按名称/正文关键词搜索、命中片段及真实定位、处理状态、打开、定位、重新处理和删除。删除只操作导入副本，不删除原始位置的文件。
- 笔记：创建、纯文本编辑、自动保存、列表、搜索和删除；不做文件夹、标签或富文本系统。
- 设置：AI 服务、数据与隐私、关于三个分区。保存与连接状态分开，对话和智能检索单独测试；高级参数按需展开，但内容外发和费用说明可见。有效智能检索服务/模型变更后，仅在用户另行确认时批量重新处理，不因对话模型变更重建。显示实际数据位置和本地诊断，不提供未实现的备份/导出按钮。

## 文件与公开网页保存边界

- 本地单文件最大 1GB（1024MB），PDF 最多 3000 页，边界值允许。复制前检查磁盘空间，PDF 提供逐页解析／扫描识别进度。导入和重新处理等待 Worker 真正完成或退出，不再因固定 30 分钟等待造成假失败。大文件仍可能因内存、空间、加密或损坏而失败，并提供重试。
- 首页和资料页的“添加链接”只接收公开 HTTP(S) 网页。正文和不可执行的原始响应存档都保存在本地；离线查看、检索、问答及段落引用复用现有资料架构，不新增导航。
- 相同规范化提交网址与正文去重；正文变化另存独立快照，不覆盖旧引用。重新处理只重建本地索引；迁移携带快照，删除不影响网站或外部文件。
- 抓取独立限制为解压后 20MB、总网络读取 60 秒、最多 5 次重定向；逐跳校验所有 DNS 地址并固定连接目标。不使用浏览器 Cookie、模型密钥、代理凭据，不执行 JavaScript。不支持登录页、验证码、动态渲染、文件直链、递归抓取或远程图片／视频下载。
- 网址及正文不进入拾微统计和错误日志；在线智能检索仍可能把网页派生正文发送给用户选择的模型服务。不是云收藏或实时联网搜索。

## 明确不做

账号、云知识库、同步、用户内容上传、移动端、协作、笔记文件夹/标签、知识图谱、Markdown 富文本编辑器、插件市场、工作流、Agent、GraphRAG 和复杂企业权限均不属于 MVP。

2026-09-15 决定：MIT 开源，移除拾微后台、统计与错误上报，不自动检查或安装更新。用户主动前往 GitHub 下载。此决定取代此前 v0.3 发布控制面与默认统计要求。

本地优先不等于所有文本永不外发：在线对话可以发送问题、有限证据和必要对话上下文；在线智能检索会依次发送待索引资料的全部派生文本片段，并发送查询文本生成向量。目的地是用户选择的模型服务，不是拾微统计服务；指向本机的模型服务不应描述为必然联网。首页、设置与隐私说明必须使用同一真实边界。

## 最终验收

在新 Windows 电脑安装后，导入 `fixtures/demo-knowledge`，询问“我之前数据库恢复以后 PDB 打不开是怎么解决的？”，系统必须召回 Oracle 记录、生成基于资料的回答、显示引用片段，并能打开对应文件。
