# 拾微 0.1.2 对话与中文检索验收

日期：2026-09-04。架构：Tauri 2 + React/TypeScript + Python Worker。

## 修复范围

- 使用随 Worker 打包的 jieba 词典，中文搜索分词、停用词过滤，保留文件名和错误码。
- 文件名/标题支持参数化子串召回；两字正文词在 FTS 未命中时使用有上限的回退查询。兼容既有 Unicode/trigram 索引，不重导资料、不重建向量。
- 日常聊天、文件定位、资料库概览、资料问答、未找到、澄清分别处理；本地规则优先，复杂未命中问题最多一次结构化意图识别，输出校验失败安全回退。
- 文件卡片和正文引用分离；最近六条消息以及仍存在的真实来源用于追问。多份资料不自动挑选。
- 通用回答不冒充个人经历；资料回答校验引用。跨 token 的伪造引用也在流式输出时过滤；没有有效引用的模型资料结论不作为可信答案展示。
- 增量迁移版本 4 保存回答类型、运行模式、提示状态和来源关联。迁移事务覆盖 DDL 和迁移标记；旧消息可以读取。
- 即时用户消息、同步发送锁、请求 ID 关联、会话加载锁、过期响应丢弃、失败重试。历史列表刷新失败不把成功答案改成失败。
- 设置显示“配置已保存”，模型未配置、连接/权限/额度/超时错误和资料未找到分开显示。

## 验证结果

### 自动化回归

- Python：77 项通过，包含原有 52 项及新增检索、路由、迁移、来源持久化、追问、无模型、模型错误、意图识别失败、引用过滤与提示注入边界检查。
- React：21 项通过，包含原有 10 项及即时消息、重复发送、IME、StrictMode 首页请求、切换会话、重新进入页面、加载锁、重试、源文件副本回退及事件请求 ID 校验。
- Rust：9 项通过，包含原有 7 项及模型错误分类、过期流式事件过滤；包括实际启动 Python Worker 并完成 RPC 往返。三层合计 107 项通过。
- TypeScript 编译和 Vite 7 生产构建通过；验收专用 `qa/` 入口不进入生产包。

### 现有资料库：只读验证

### 隔离联调

`scripts/smoke-chat-worker.py` 创建临时资料库与合成 PDF/TXT，经过真实 JSON Lines Worker 协议导入、中文查找、来源路径检查、连续追问和历史读取。临时测试不打开用户资料库，不加载真实密钥。

浏览器验收入口 `apps/desktop/qa/chat.html` 使用 Tauri 官方 IPC mock 作为开发桥，连接真实 Python Worker。已实测文件定位卡片、指定文件提问、原文与页码侧栏、新建会话、问候回答。浏览器桥不执行 OS 打开动作；卡片打开/定位的调用与原件失效后的副本回退由前端测试覆盖。

真实模型测试使用 Windows 凭据管理器中的既有聊天密钥，仅发送“连接测试，请只回复 OK。”，收到流式文本；不加载个人资料，不修改配置，不记录密钥或模型回复内容。脚本必须显式传入 `--confirm-benign-live-request` 才运行，不属于自动测试流程。

## 边界

- 本版仍未代码签名。
- OS 文件打开与资源管理器定位的完整人工桌面点击验收受当前环境的原生 UI 自动化能力限制；不能用浏览器 IPC mock 结果冒充原生点击验证。
- 自动化引用检查证明引用 ID 和来源来自提供的真实片段，并不等于对任意大模型回答语义正确性的保证。
- 本次只修复对话与检索，不引入分类/发现导航、云服务或重新实现旧 Electron 原型。
