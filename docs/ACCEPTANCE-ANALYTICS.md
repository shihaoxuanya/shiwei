## 完成范围

- 在既有 FastAPI 控制面增加严格白名单采集接口与管理员汇总接口，统计使用独立 control-analytics.db，不改用户知识库或原有版本数据库 schema。
- 汇总活跃安装、首次观测、导入／提问／有证据回答／拒答／来源查看、版本分布、成熟留存、错误类型和更新事件；最近 7／30 天选择、每 60 秒刷新、真实空数据和故障重试。
- 沿用旧后台纸白／靛蓝视觉与版本管理流程。不会将事件占比标成回答准确率，或把更新事件相除当作精确安装成功率。
- 新生产安装默认开启、不弹确认框；旧的关闭状态保留，损坏设置关闭上报，设置提供说明和即时关闭。开发构建和浏览器预览不自动上报生产数据。
- 原生与服务器双重校验；随机 ID 经 HMAC 处理；请求／容量／时间范围限制；90 天保留、每小时清理；统计故障不阻断版本服务。
