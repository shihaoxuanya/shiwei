# 拾微 0.1.3 对话体验验收

日期：2026-09-04。Tauri 2 + React/TypeScript + Python Worker。上一版本 0.1.2 的中文检索、证据边界、引用校验和分类错误信息均保留。

## 实现

- 固定工作区头部、独立历史栏、独立消息滚动区、底部多行输入区。
- 历史按标题及正文搜索，参数化 LIKE、通配符转义、每页 50 条、回复预览。无需迁移、重新导入资料或重建向量索引。
- 按会话缓存草稿、阅读位置、待处理请求、回复及错误；跨导航保留；生成结果只更新其原始会话；全局同步发送锁避免重复/排队请求。
- 中文 IME、Shift+Enter、长问题提示、一键文件总结、后台等待状态、回到最新消息。
- Markdown 标题/列表/表格/代码、复制反馈、可验证的正文引用按钮、非模态原文面板、Esc 和焦点恢复。
- 原始资料、模型密钥和数据库写入边界保持不变。开发专用 HTTP/模拟模型入口不在生产构建中。

## 实际交互验收

`qa/ux.html` 使用完整应用界面、真实 Python WorkerServer 和临时合成 PDF/TXT。仅模型替换为明确标注的确定性测试网关，用于长回答、延迟和错误。此处不连接真实模型，不加载用户资料或凭据。

已操作验证：

1. 76 段历史中通过正文“磁盘容量”找回第一段旧对话，打开正确记录。
2. “我的简历在哪”返回合成 PDF 的真实本地文件卡；点“总结这份资料”直接发送。
3. 长 Markdown 回答正常流式渲染，输入框始终可见，文档本身不产生额外整页滚动。
4. 模拟慢响应后回看旧消息：回复完成时消息滚动位置仍为 0，“回到最新消息”可用。
5. 等待回复时填写两行草稿，切到设置再返回，草稿和进行中的回答都保留；完成后切到资料页再返回仍保留。
6. 来源打开时继续写多行追问；Esc 关闭，焦点回到原出处按钮，草稿保留。
7. 1024×680：页面宽高无溢出；来源宽 292px，聊天/输入区宽 544px，输入区底边为 680px，互不覆盖；测试后恢复默认窗口。

截图与审查过程见 [CHAT-UX-AUDIT.md](CHAT-UX-AUDIT.md)。截图中资料均为合成资料，不是用户简历或工作记录。
