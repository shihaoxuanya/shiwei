## 已确认基线（不是仅凭截图推断）

1. 首页大型 Worker 卡片占主区域，记一下入口弱；首页只有问答片段外发的说明，遗漏在线向量索引会发送全部派生文本。
2. `App.tsx` 资料筛选仅对 filename + originalPath 做 includes；现有 `search_lexical` 可复用，不需新索引或 LLM。
3. 设置所有字段、隐私、更新串在同一长页；测试连接将对话与向量捆绑；保存和重建同列。
4. 旧统计只持久化 enabled 布尔值，历史默认 true 不能证明主动选择；新结构区分默认与主动选择。迁移遵循上述最新默认开启决定，不把默认状态标记为主动同意。
5. 笔记真值与全文投影同事务保存，但 RPC 还同步等待远程向量更新；重复空白创建、重进恢复、关闭落盘与失败重试需补足。
6. 对话已有草稿、请求标识和输入法判断；缺真实停止。匹配旧天气资料时可能进入个人证据通路，没有实时能力边界。

## 验收维度

首次使用/无 Key；首页和资料同一导入；中文与技术词正文命中及来源去重；原件删除安全；笔记保存失败/关闭/版本/删除；三类对话路由/停止/重试/切换/IME/滚动；分项连接测试/凭据隔离/确认后重建；统计默认、迁移、关闭队列；模糊回忆/数字范围/事实与推断/引用/拒答。

视觉检查：1366×768、1920×1080；浏览器尺寸与 Windows 实际 100%/125%/150% 缩放分别记录，不混同。截图使用合成数据，无个人内容或凭据。

### 实际运行与证据边界

1. Vite 本地预览已运行。`scripts/qa-desktop-ux.py` 在 loopback 接真实 Python Worker 和独立合成 SQLite/FTS；浏览器模型输出是显式模拟，不能当作真实厂商模型验收。系统文件选择、OS 打开、凭据与统计在这个浏览器桥接中为 QA 替身，不把它们计作 Tauri 系统集成通过。
2. 实际浏览器操作验证：正文“水杉”命中名称不含该词的资料；损坏 PDF 的失败原因；笔记控制性保存失败及重试；会议来源抽屉与完整可见输入框；生成中停止、停止反馈；设置三个分区；空库和有内容首页。保存失败、模型超时/错误由合成测试注入，不触及用户资料。
3. 最终 Tauri Debug 可执行文件已单独编译并于本机实际启动，原生 Worker 正常，合成首页最近内容/损坏 PDF 反馈/笔记编辑区正确加载。使用 `SHIWEI_DATA_DIR`、`SHIWEI_QA_CONFIG_DIR`、独立 WebView 目录及 `SHIWEI_TELEMETRY_DISABLED=1`；无模型密钥，不发生产统计，不覆盖用户正在运行的旧程序。
4. 最终原生“编辑后立即关闭并重启”人工全链路未完成：系统自动化 value 操作不支持，随后检测到用户输入及窗口最小化，停止操作以免争抢窗口。相应自动保存/关闭保护测试通过，但不能替代此真机检查。
5. 1366×768 和 1920×1080 是浏览器 CSS 视口验收；原生窗口只按本机当时设置检查。Windows 100% / 125% / 150% 全矩阵、最终安装包、Mac 原生验收不在已完成项内。

### 隐私、旧数据与构建产物

- 原文件不改写；笔记真值与派生 FTS 保持原设计，不重置数据库，不批量重建用户库，不删除任何用户笔记/文件。测试只写 `output/desktop-ux/` 独立合成目录。
- 已有模型、服务地址和密钥不被静默换厂商；凭据升级只加强存储绑定，不能把旧厂商密钥带到新端点。仅切换对话模型不触发向量重建。
- 本机保存与模型调用分开：在线对话发送当前问题、必要历史与证据；在线 embedding 建索引会依次处理全部派生文本片段，查询会发查询文本；本地端点由本地服务处理。不能把“没有上传拾微统计服务”写成“不会离开电脑”。
- 统计不是原始日志：仅随机安装标识、版本、基础事件/数量、固定错误类型和受限模块信息；不传正文、文件名/路径、问题/回答、密钥。关闭不补传；服务端已收历史依现有 90 天保留策略，不即时删除。无新增 SDK、远程字体或内容采集。
- 单独 Debug 构建：`output/desktop-ux/final-native/shiwei-desktop.exe`，27,954,688 字节；SHA-256 `5CBE99A19963E9C4EE725C2125DD1DAA03E3339C352975F13B279DF9A594B61E`。基于当前 0.3.2，使用开发 Worker，不是已发布安装包。无 Git 推送、Release、服务器部署或用户更新。

### 已知限制与优先级

- **P2 / 待人工验收**：原生编辑后立即关闭/重启、真实中文输入法组合键、Windows 三档系统缩放全矩阵及完整原生文件对话框/定位操作。自动化覆盖相关逻辑，但不以浏览器替身冒充 OS 验收。
- **P2 / 已知边界**：停止已阻止迟到答案写入；上游同步 HTTP 尚在等待响应时，Worker 普通请求仍可能等现有超时/返回后继续，UI 明确显示正在停止，未宣称立即终止服务商计费。
- **P2 / 原有缺项**：没有一键完整备份/导出入口，设置明确说明，不放假按钮、不扩大本轮开发。
- **P3 / 工程提示**：前端集成测试有 React act 警告，控制平面依赖有弃用提示；测试均通过。构建约 502 KB 的分包大小提示未影响产物，未为消除提示进行无关架构重写。
