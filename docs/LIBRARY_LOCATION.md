# 资料库更改位置验收记录

日期：2026-09-08。版本保持 0.3.2；本次未发布安装包。

## 行为与安全边界

设置 → 数据与隐私 → 更改位置，通过原生文件夹选择器选择父目录。应用在其中创建唯一的 `拾微资料库-<随机标识>` 子目录，不覆盖已有文件。

迁移前保存笔记，等待导入、问答与索引工作结束；迁移期间阻止编辑、退出和更新。Python 使用资料库与位置配置独占锁、一致 SQLite 快照、文件 SHA-256、数据库完整性与外键校验。仅在副本中重定位托管路径，不修改原始正文、引用身份或重建索引。全部验证成功后原子切换外部位置配置。

失败保留原库；成功也保留原目录副本，不自动删除。重启读取已保存的新位置；位置配置损坏或目标库丢失时明确报错，不静默创建空库。通信中断后的界面重新读取当前位置，避免错误宣称切换一定未发生。

## 实现模块

- React：library-location 状态与活动锁、设置选择/确认/进度流程、笔记保存及迁移后资料/对话缓存刷新。
- Rust：library_location 配置路径、library_relocate 命令、Worker 独占调用、关闭/更新保护。
- Python：storage/library_location、storage/library_lock、Importer 位置解析及 Worker RPC。
- 自动测试：前端交互、Python 迁移与真实索引集成、Rust 生命周期测试；scripts/qa-library-location.py 提供独立合成资料库的真实 Worker 验证。

## 限制

仅验证本机 Windows 本地目录。未进行 Mac 原生界面、跨物理磁盘及真实断电测试；不接受网络路径、系统根目录、符号链接或 junction 目标。旧版本不遵守新增资料库锁，不应与旧版同时写入同一资料库。所有测试使用合成资料，未操作用户真实资料库、模型密钥或生产统计设置。
