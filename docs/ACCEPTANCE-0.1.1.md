- 保留原有纸色、靛蓝、四项导航，将设置从自由输入改为厂商/地域/模型/检索方式选择；高级地址和自定义模型 ID 仍可用。

- 保留页码、100MB/300 页限制、加密及损坏错误提示；长导入使用独立的 30 分钟 RPC 超时。
