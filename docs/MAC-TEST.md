# 拾微 Mac 内测说明

适用：Apple Silicon（M1 / M1 Pro 及后续 Apple 芯片），macOS 14 或更新系统。不支持 Intel。本包基于 0.3.2，完整携带本地 Python Worker，不需要安装 Python、Node 或开发工具。

## 安装与首次打开

1. 从拾微公开安装包库下载名称含 `macos_arm64_test` 的 DMG。版本页面的 SHA256SUMS.txt 可用于校验下载完整性。
2. 打开 DMG，将「拾微」拖入「应用程序」，随后从「应用程序」启动。
3. 本内测版仅作 Ad-hoc 临时签名，没有 Apple Developer ID 签名及公证。macOS 可能提示开发者无法验证：确认下载来源后，可到「系统设置 → 隐私与安全性」对**拾微这一应用**选择“仍要打开”。不需要也不应关闭 Gatekeeper、系统完整性保护或全局安全检查。
4. 若系统禁止单独允许，或显示应用损坏，不要运行绕过安全检查的终端命令；先反馈原始提示、系统版本及校验结果。

这不是 App Store 或正式自动更新版本，不会从 Windows 稳定发布通道下载安装包。后续测试包手动替换应用；不要删除本地资料目录。

## 本地数据与隐私

资料与笔记默认保存在当前 Mac 用户的 `~/Library/Application Support/Shiwei/data`，模型配置位于应用的系统配置目录，API Key 使用 macOS 钥匙串。测试包不携带 Windows 用户的数据或 API Key，也不在两台电脑间同步。

首次使用仍需配置自己的模型服务。原始文件、笔记和索引留在本机；生成回答所需片段会发送给用户选择的模型。基础使用统计沿用设置页说明及随时关闭机制，不收集正文、文件名、路径或密钥。自动验收使用合成资料，并关闭生产统计。

请先使用可替代的测试资料。当前产品没有完整的备份恢复入口，删除笔记不可恢复；不要把唯一一份重要记录仅保存在内测版中。

## 测试用户验收

- 首次安装能打开，无终端黑窗；退出拾微后无残留 Worker，重新打开资料和笔记仍在。
- 添加文件、添加文件夹和拖放可用；中文与空格路径、普通 PDF、扫描 PDF、DOCX 均可导入。
- 模型密钥保存后重启可用；拒绝钥匙串或文件权限时给出明确错误，不把密钥写进日志。
- 使用合成的 `2025年9月3日会议` 笔记，记录 Oracle 至 TiDB 迁移、全量 38~50 天、增量 7~14 天。
- 模糊询问上次会议、Oracle 迁移日期及会议内容能召回同一笔记，数字区间和来源对应正确；没有 MongoDB 记录时应拒答。
- 点击来源可查看原文，文件可打开并在 Finder 定位；中文输入、滚动和继续追问正常。

请反馈：Mac 芯片、macOS 版本、测试包名称、复现步骤与错误提示。不要在反馈中发送 API Key 或含个人资料的完整诊断日志。

CI 的自动检查不等同于你的 Mac 首次下载、Gatekeeper 授权和 Finder 交互检查；版本验收记录必须分别注明。
