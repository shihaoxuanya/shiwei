# 大文件与公开网页保存验收（2026-09-10）

本轮是本地功能实现与验收，沿用 0.3.4 工作树，不发布新版、不推 GitHub、不修改服务器，不替换已分发的签名安装包。

## 实现

- Python `ingestion/limits.py` 为本地导入统一定义 1 GiB 和 3000 页（均包含边界）。原件流式哈希／复制，目标磁盘需容纳文件并预留 64MiB；复制异常只清理自身临时文件。PDF 逐页解析／OCR 进度与资源释放。
- Rust `worker_client.rs` 的导入、URL 保存、重新处理、向量重建等待真实终态或进程退出；不再因客户端 30 分钟超时提前解锁。问答超时不变。
- `web_fetch.py` 公网地址、DNS 全量校验及 IP 固定连接，TLS 使用原始主机名验证；每次重定向重验，最多 5 次、解压最多 20MiB、网络总预算 60 秒。不使用系统代理、Cookie、浏览器会话或模型密钥。
- `web_extract.py` 使用已有 BeautifulSoup/lxml 离线提取文本、列表、代码和表格，过滤脚本、导航等内容，拒绝空白／登录／验证码／纯动态正文。
- `importer.py` 保存不可执行 `.websnapshot`（原始响应 Base64 + 固定 canonical 正文）与数据库来源。规范化**提交网址** + 正文哈希去重，不合并不同提交网址；变化创建独立快照，重新处理绝不联网重抓。
- SQLite 增量迁移 7 增加 `original_url/final_url/captured_at/body_hash`。网页复用原有分块、FTS 和可选向量链路；检索与历史引用携带 `web_page/sourceId` 和 URL 元数据。相同快照重新处理保留匹配的 Chunk / Citation 身份。
- 首页／资料页共享“添加链接”，复用进度与失败重试；正文安全文本渲染，默认打开本地快照。[S#] 定位正文段落，显示保存时间，不伪造 PDF 页码。打开原网页需显式点击，主进程仅接收已保存来源 ID。
- 快照跟随整库迁移；删除仅影响托管副本，保留外部文件、网站、其他资料及迁移前原库。

## 限制与说明

- 1GiB 测试文件使用未引用填充流、单页正文构造，证明真实尺寸接受、流式复制和可检索，不代表复杂 1GB 文档都能数秒解析。内存、磁盘、加密、损坏及大规模扫描仍可能导致可重试失败。
- 网页只保存公开静态正文，不支持登录、JavaScript 渲染、验证码、文件直链、远程媒体、递归抓取或自动更新收藏。
- 网站 HTML 各异，正文启发式提取不能保证每个公开网站都成功。失败明确显示，不会把空正文标成成功。
- 未创建新安装器、GitHub Release 或服务器更新。本轮原生测试构建不是新的正式分发包；既有 0.3.4 签名安装包内容保持不变。
