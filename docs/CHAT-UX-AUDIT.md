# 对话体验审查与优化

日期：2026-09-04。基线：拾微 0.1.2。改进版：0.1.3。

使用 Product Design 的截图优先审查流程，先体验再修改；既有纸色、靛蓝、固定四项导航不变。所有截图来自运行中的浏览器开发入口，已保存并重新打开检查，不是设计示意图。窗口默认为 1280×720，额外测试 Windows 最小窗口 1024×680。

## 1. 开始与找历史 — 原体验：需要改进

横排仅显示最近六段对话，重复标题缺少区分信息。大标题、说明、历史和输入框占据页面上方，历史入口和阅读区没有清晰分工。

![优化前入口](../output/chat-ux/before-empty.png)

改进：独立且可收起的历史栏，显示标题、回复预览、日期/草稿/新回复状态。按标题和聊天正文搜索整个本地历史，每页 50 条，可继续加载。不是只过滤屏幕上已加载的六条记录。

## 2. 连续提问 — 原体验：严重摩擦

两轮对话后滚到回答末尾，输入框已经离开视野。文件卡片的“总结”只填入顶部输入框，还要返回顶部再点发送。输入框是单行，难以检查长问题。

![优化前：两轮回答末尾](../output/chat-ux/before-followup.png)

改进：对话消息独立滚动，底部输入区常驻；多行输入自动增高，Enter 发送，Shift+Enter 换行，中文输入法确认不误发。超过 2000 字提示拆分，保留原文而不静默截断。文件卡片总结一键发送，但不覆盖已写好的另一条草稿。

![同一资料、同一两轮对话的优化后状态](../output/chat-ux/after-followup.png)

并排检查上述前后截图：目标是改变交互结构而非像素复刻。阅读末尾现在仍可输入；历史留在侧面；知识回答不再重复整张文件元数据卡片，文件定位卡与正文引用仍然分离。

## 3. 看出处 — 原体验：打断阅读

原侧栏使用全屏遮罩挡住对话，Esc 无效，焦点仍留在背景出处按钮。路径信息比原文更突出。

![优化前来源面板](../output/chat-ux/before-source.png)

改进：非模态来源栏和对话并排，原文优先、路径折叠。窄窗口看来源时自动收起历史；输入框始终可用。Esc 关闭并回到触发按钮。正文中的已验证 `[S1]` 标记也能打开出处，不必翻到整段答案末尾；未验证 ID 不创建来源操作。

![最小支持窗口中的原文与追问](../output/chat-ux/after-minimum-source.png)

## 4. 等待、回看与切页 — 原体验：连续性不足

原页面缺少“回到最新”入口。代码检查与交互测试确认，页面卸载会丢失选中会话、未发送草稿和当前流式显示；切换会话会丢弃旧请求的客户端结果。

改进：内存工作区按会话分开保留草稿、回复、错误和阅读位置。回答绑定发起会话，不绑定当前屏幕。可以边等边写下一条，切到设置后再回来；不会重复发送或串话。只有一段生成可运行，切到其他对话时显示明确等待状态和返回进度入口。回看旧消息时不强制跳底；需要时主动点击“回到最新消息”。

![回看旧消息时保留位置](../output/chat-ux/after-reading.png)

## 阅读与可访问性检查

- Markdown 列表、标题、表格、代码块正常排版；回答/代码可复制，失败有提示。
- 模型 Markdown 不执行 HTML，不自动请求远程图片，不导航嵌入式应用；外部链接可复制。
- 已测键盘发送、输入法、Esc、来源焦点恢复、可见焦点样式、长表格滚动、长文本换行与 reduced-motion。
- 这不是完整的屏幕阅读器或 WCAG 合规审计；浏览器视觉验收不等同于原生窗口像素验收。

## 保留的边界

草稿只在本次应用运行期间保留，不写入浏览器存储；退出软件后持久化的是 Worker 已保存的完整对话。没有增加“停止生成”假按钮，模型超时和错误仍由真实链路返回。没有加入分类、发现、账号或云同步。
